# CimiLoop V1 发布检查清单

> 所有“已通过”项必须能指到测试、demo 或脚本输出。未列出的能力不得在 README 或 UI 中宣称支持。

## 1. 基线与制品

- [ ] Node.js 24.15.0 + pnpm 12.4.2：`npx --yes --package node@24.15.0 --package pnpm@12.4.2 -c "pnpm test"`
- [ ] `pnpm schema:export` 后 `git diff --exit-code -- packages/protocol/schemas`
- [ ] `git diff --check` 无空白错误
- [ ] 包依赖方向：`protocol ← store ← kernel ← operator/adapters`；`portability` 只依赖 `protocol`

覆盖：根 `package.json` engines、`pnpm-lock.yaml`、本清单第 6 节。

- [ ] Feature 闭环：`tests/acceptance/v1-north-star.test.ts`

- [ ] CLI 表面：`tests/acceptance/v1-cli.test.ts`
- [ ] Demo：`scripts/demo-v1.ps1`，以及 `demo-m1.ps1`–`demo-m4.ps1`

## 3. 安全与恢复

- [ ] 故障注入：`tests/faults/v1-faults.test.ts`
