## 4. 已知限制与剩余风险

- 空目标 CommitImport 不物化可查询 Project，只接受 dormant report。
- 导入后不会自动获得 Runtime ownership。
- Close/Archive/Cancel/Supersede 不改写 Change lifecycle_state。
- Windows 全量并行时 CLI 冷启动慢；M1/M2 CLI 超时为 240s，断言未降低。
- after-effect 故障注入依赖 2s 超时窗口，极端机器负载下仍可能竞争。
- 未发布全局安装包；云 DevOps、登录、实时协作、完整 SPA 未实现。
- CLI 不组装 ExternalDeliveryWorker；外部副作用仍由 DevOps Adapter / 人工 `record-result` 回传（与 M4 冻结范围一致）。

## 5. 独立审查修复（冻结后）

独立审查将 V1 评为 Not ready。本轮已修复 Critical / Important，未把修复压进冻结提交：

- AssessImpact 由分类器决定 validity；调用方覆盖返回 `IMPACT_CONCLUSION_MISMATCH`。
- 生产 Release authorization digest 纳入 Evidence fingerprint 与最新 Independent Evaluation input digest；批准时对照 live digest，过期返回 `DECISION_REQUEST_EXPIRED`；QueueDeployment 再次要求最新 Evaluation ALLOW。
- Command 必须绑定已持久化 Actor（`ACTOR_NOT_FOUND`）；责任命令要求 Human Actor + `human_cli`/`human_workbench` origin。
- Protocol origin 增加 `human_workbench`；Workbench Decision 使用该 origin。
- RecordEvidence 的 `producer_role` 必须与 origin 一致（`PRODUCER_ROLE_MISMATCH`）；Human 不能自称 evaluator。
- RecordArtifact 对 `file:` 引用核对字节 digest（`ARTIFACT_DIGEST_MISMATCH`）。
- Export/Import 历史 digest 排除 portability Event 与对应 Outbox，相同项目再导入视为 idempotent。
- Context Pack source digest 改为 Contract/Policy/Plan 的稳定哈希。
- Close/Cancel/Supersede 在存在 unknown/pending 外部操作时拒绝；ProposeClose 记 `external_side_effects` gap。
- 生产 Release Decision 的 required role 改为 `release_owner`，不再复用 `project_owner`；Solo bootstrap 同时分配该角色。
- CompleteEvaluation 按 Requirement Set 的 required items 评估，缺失项或仅有 human Evidence 不能 ALLOW。
- AssessImpact 不再把调用方 `rule` 字符串当作 integrity/mismatch 分类开关。
- 已 Close/Cancel/Supersede/Archive 的 Change 拒绝再创建执行或交付事实（`CHANGE_ALREADY_TERMINAL`）；Archive 将 operating_status 置为 Paused。
- CommitImport 重新读取 staging bundle 的 content_digest，摘要被改写则拒绝。
- `file:` Artifact 必须能读到本地字节；digest 对不上或文件不存在即 `ARTIFACT_DIGEST_MISMATCH`。
- CLI 增加 `evidence promote`，demo-m3/m4/v1 用 junit 提升 `AC-run` 与 `integrity.digest`。

新增/强调的 Domain Error：`IMPACT_CONCLUSION_MISMATCH`、`PRODUCER_ROLE_MISMATCH`、`ARTIFACT_EVALUATION_NOT_ALLOWED`、`ACTOR_NOT_FOUND`、`CHANGE_ALREADY_TERMINAL`。

审查后锁定测试：72 files / 271 tests PASS。

## 6. 给审核 Agent 的重点

1. Kernel 是否仍是唯一状态权威；CLI/Workbench/Adapter 是否只发 Command。
2. Human Decision 是否只记录事实后重新 Gate，而不是直接改 lifecycle。
3. 未解决 Refutes 与未完成 Mandatory Knowledge 是否阻止 ALLOW。
4. 测试/生产是否强制同一 Artifact digest。
5. 未知外部结果是否禁止盲重试。
6. Export 是否不含 secret；Import 是否拒绝 DIVERGENT_HISTORY 且 ownership=dormant。
7. Attention acknowledge 是否不会关闭 Decision Request。
8. AssessImpact / Release Decision / producer_role / Artifact file digest 是否仍可由调用方绕过。
