## 1. M5 已实现

- Protocol：LearningCandidate、KnowledgeUpdateEvidence、ClosureEvaluation、ExportManifest、ImportReport、AttentionItem、Archive/Cancellation/Supersession Record；Portable schema version 为 `portable-1.0.0`，独立于 Protocol `1.0.0`。
- Store v6：上述事实 + Attention + read-model checkpoint + VACUUM INTO snapshot；`import_reports.project_id` 无 FK，以便空目标 staging。
- Knowledge Closure：Mandatory Knowledge Task 必须有版本化 External Reference + Valid Supports Evidence，或合格 Human 例外；`unavailable:` 前缀不视为完成。
- 终态：ProposeClose/CloseChange 不改写 lifecycle；Feature 需要 verified production Release；Incident 允许 verified test 终点；Cancel/Supersede 被 unknown/pending 外部操作阻止。
- Learning Candidate：status=proposed 且 promoted=false，直到接受 Decision。
- Portability：`@cimiloop/portability` 生成顺序无关 content_digest；缺失对象 `OBJECT_MISSING`；Import 先 staging，拒绝 path traversal / symlink / oversized / DIVERGENT_HISTORY。
- Workbench：Attention Queue、六阶段 Change Room、双层 timeline；mutation 只走 Kernel。
- Read Model：删除 Attention/checkpoint 后可从 facts 重建；acknowledged 不等于 Decision。
- CLI：`project export/import-stage/import-commit`、`knowledge record`、`change propose-close/close`。
- 验收：`tests/acceptance/*`、`tests/faults/*`、`tests/security/*`、`scripts/audit-v1.ps1`、`scripts/demo-v1.ps1`。

## 3. 计划偏离

| 偏离 | 原因 |
|---|---|
| 开发分支为 `codex/v1-complete` 而非分里程碑分支 | 用户要求从冻结 M0 连续完成 M1–M5。 |
| `import_reports.project_id` 去掉 projects FK | 空 Store staging 必须能持久化 ImportReport。 |
| RecordEvidence 自动创建 External Reference | Protocol 没有 CreateExternalReference，Knowledge Update 又要求版本化引用。 |
| Close 不改写 lifecycle_state | 与架构“终态是向前事实”一致，避免与 Draft→Executing 状态机冲突。 |
| Attention 使用 query-time 重建 + 可删除投影 | checkpoint 只优化，不构成权威。 |
| 空目标 CommitImport 只接受报告，不物化 Project | V1 明确不自动激活 Runtime；空目标切换保留为 dormant report，避免静默获得 ownership。 |
| Windows CLI 场景超时提升到 240s | AnyCommand 图增大后，全量并行套件下每次 CLI 冷启动约 3–8s。 |
| after-effect 故障注入超时 200ms→2s | 全量并行时 spawn 可能超过 200ms，导致 effect 未落盘就被杀死。 |
| audit-v1 不再用 Get-ChildItem -Include | PowerShell 5 会枚举损坏的 pnpm 嵌套路径并抛错。 |

## 4. 关键不变量

1. Close/Archive/Cancel/Supersede 不删除历史，也不原地覆盖 Contract/Plan/Decision/Evidence。
2. 未完成的 Mandatory Knowledge 不能 ALLOW close。
3. 未解决的 Refutes Evidence 仍阻止 ALLOW。
4. Export 不含 secret/cache/raw transcript；content_digest 与导出时间无关。
5. Import 必须 staging → 校验 → 报告；分叉历史拒绝静默合并。
6. 导入项目默认不能获得 Runtime ownership。
7. Secret 不得进入 Protocol、Event、Export、错误或测试快照。
8. 通知已读不等于 Decision。

## 7. 已知限制

- Change 生命周期仍为 Draft → IntentReady → Planned → Executing；Close 是向前事实。
- 空目标 Import 不物化可查询 Project；源 timeline/digest 可查，导入侧保持 dormant report。
- Solo Release Owner 复用 `project_owner`。
- CLI 执行路径不调用 workspace-git。
- Windows PowerShell 5 + CLI 冷启动较慢；断言未降低。
- 尚未发布全局 npm 包。
