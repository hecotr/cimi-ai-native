# CimiLoop V1 适配器指南

> V1 支持 Claude Code Runtime Adapter 与本地 Command DevOps Adapter。Adapter 不能写权威状态。

## 1. Runtime Adapter

输入仅限：Work Item、Context Manifest 路径、Worktree 路径、Capability Binding。stdout/stderr 写入 Local Files 并记录 digest/reference。exit 0 不等于业务成功。进程未知必须映射为 Failure/Blocker，不得猜测成功。

- 实现：`packages/runtime-claude-code/src/adapter.ts`
- 测试：`packages/runtime-claude-code/test/adapter.test.ts`
- Demo：`scripts/demo-m2.ps1`、`scripts/demo-v1.ps1`（fake-runtime 路径）

Secret 只能通过受控 env 注入，日志与 Event 必须脱敏。禁止把 `process_env`、token、私钥写入 Protocol 或快照。

覆盖：`tests/security/v1-security.test.ts`。

## 2. DevOps Adapter

输入/输出必须通过 Protocol Schema。禁止 secrets 与 `process_env`。Command Adapter 使用 `spawn(shell:false)` 与 argv，拒绝 `;`、`&&`、管道。operation key 唯一；attempts 只追加；当前外部状态由最新 Result / Reconciliation 投影。

- 实现：`packages/devops-command/src/adapter.ts`
- 测试：`packages/devops-command/test/adapter.test.ts`
- Demo：`scripts/demo-m4.ps1`

未知结果不得自动重试部署。必须走 `RequestReconciliation` / `RecordReconciliation`。

覆盖：`packages/kernel/test/reconciliation.test.ts`、`tests/security/v1-security.test.ts`。

## 3. Evaluator

Evaluator 独立于 Executor transcript，不能写生产代码。`CompleteEvaluation` 由 Kernel 计算 Gate，忽略自评分数。只能 promote `junit`、`tap`、`cimiloop_test_v1`。解析失败必须 Inconclusive + Invalid Impact。

覆盖：`packages/kernel/test/evaluation.test.ts`、`tests/acceptance/v1-exceptions.test.ts`。
