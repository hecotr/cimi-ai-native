# CimiLoop V1 操作指南

> 基线：Node.js 24.15.0 + pnpm 12.4.2。尚未发布全局安装包，从本仓库源码运行。

## 1. 安装与检查

```text
npx --yes --package node@24.15.0 --package pnpm@12.4.2 -c "pnpm install"
npx --yes --package node@24.15.0 --package pnpm@12.4.2 -c "pnpm check"
npx --yes --package node@24.15.0 --package pnpm@12.4.2 -c "pnpm test"
```

锁定测试命令见根目录 README。演示：

```text
powershell -NoProfile -File scripts/demo-v1.ps1
```

覆盖：`tests/acceptance/v1-cli.test.ts`、`scripts/demo-v1.ps1`。

## 2. 初始化

在 Git 仓库根目录：

```text
node apps/cli/dist/bin.js init --owner-name "Owner" --owner-email "owner@example.com" --yes
```

一个 Repository 对应一个 Project。权威库在 Git Common Directory 下的 `cimiloop/project.db`。Agent 不得借用该 Human Actor 批准 Gate。

覆盖：`tests/scenarios/m0.test.ts`、`tests/scenarios/m1-cli.test.ts`。

## 3. Workbench

```text
node apps/workbench/dist/bin.js --project-dir <repo>
```

仅监听 `127.0.0.1`。首页提供 Attention Queue、Decision Inbox、Change 列表、Active Runs、Environment/Release。Change Room 分 Intent / Plan / Execute / Evidence / Delivery / Close。Mutation 只提交 Decision。`?view=run` 显示技术日志引用。

覆盖：`apps/workbench/test/workbench.test.ts`。

## 4. 完整 Feature 生命周期

1. `change create` → Draft
2. `governance bootstrap-solo`
3. `contract submit` + `contract request-review` + Human `decision submit`
4. `plan submit` + `plan request-review` + Human `decision submit` → Planned
5. `scheduler tick` → Work Item；`work-item claim/execute`（fake-runtime 或 Claude Code adapter）
6. `artifact record` → 不可变 digest
7. `claim submit` + `evidence record` + `evaluate complete`（Kernel 忽略模型自评）
8. `environment register`（test）+ `release create --kind test` + queue/record-result 直到 verified
9. `environment register`（production）+ `release create --kind production` + Human release decision + 同一 digest verify
10. `knowledge record` 完成 Mandatory Knowledge Task
11. `change propose-close` 得到 ALLOW 后 `change close`

覆盖：`tests/acceptance/v1-north-star.test.ts`、`scripts/demo-v1.ps1`。

## 5. Recovery 与未知结果

未知外部操作必须 `deployment reconcile-request` / `reconcile-record`，禁止再次 `release queue`。Production verify 失败走 Recovery，不创建 Repair Work Item。Test verify 失败创建 Repair Work Item。

覆盖：`tests/faults/v1-faults.test.ts`、`packages/kernel/test/delivery-*.test.ts`。

## 6. Backup / Export / Import

```text
node apps/cli/dist/bin.js --json project export
node apps/cli/dist/bin.js --json project import-stage --file bundle.json
node apps/cli/dist/bin.js --json project import-commit <report-id>
```

Export 使用一致性 snapshot，缺失对象失败。Import 先 staging；相同历史幂等；分叉拒绝。导入 ownership 保持 dormant。

覆盖：`packages/kernel/test/export.test.ts`、`packages/kernel/test/import.test.ts`、`tests/acceptance/v1-exceptions.test.ts`。
